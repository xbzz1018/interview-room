# 合成项目材料：团队知识检索工具

此文件仅用于演示，不代表使用者的真实经历，也不包含生产成绩。

## 业务与个人工作

场景是小团队从 Markdown 文档里查询约定。我负责文档上传、按项目筛选、片段检索及引用展示，没有负责模型训练。

## 方案与取舍

文档按 token 预算切块，保留标题和来源版本。先按项目过滤，再做语义召回；回答只引用本轮检索到的片段。缺少证据时说明材料不足，请用户补充。

编辑先处理新内容，成功后切换版本；旧会话继续引用旧快照。演示版使用 SQLite 和本地向量，未验证多实例并发。

## 验证与限制

固定问题覆盖同名项目、文档更新、尾部唯一事实和无答案四种情况。尚未填写真实样本量、召回成绩或延迟分位数，不应编造百分比。

## 建议练习

说明为什么同时需要条件过滤与向量检索；编辑失败时如何保留旧资料；如何检验引用来自正确版本。参考答法应区分材料已有信息与可选改进，不把未实现方案说成已完成。
