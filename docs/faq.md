# 常见问题 (FAQ)

### 1. 为什么上传录音后的转写结果不准？

* **先看原始音质**：远场收音、底噪、回声、多人重叠说话，都会明显拉低转写质量。
* **再看输入方式**：上传录音和浏览器实时录音不是一回事。上传文件转写本身不依赖浏览器麦克风权限。
* **最后看分析前文本**：转写结果拿到后，建议先快速人工修一遍再开始分析，尤其是公司名、技术名词和英文缩写。

### 2. 生成复盘报告特别慢怎么办？

耗时受材料长度、输出长度、模型推理强度和网关影响。报告逐段保存，完整正文可先读，画像继续后台同步；分阶段展示不保证推理本身提速。画像失败可单独重试。保留你选择的模型与强度，受控对照后再决定是否调整。进程退出后未完成正文需要重新生成，详见 [恢复边界](project-case.md)。

### 3. 录音上传后为什么不能转写？

上传录音转写依赖额外的语音服务配置。如果没有在“设置”中保存 DashScope API Key 和相关 OSS 凭据，最稳妥的做法是直接粘贴逐字稿文本进行分析。

### 4. 为什么我看不到注册入口？

默认配置下 `ALLOW_REGISTRATION=false`，所以前端不会开放注册入口。如果你要开放注册，需要在 `.env` 里显式开启。

管理员也可以在「设置 → 账户」中修改这个开关；保存后的值会持久化到 `data/system_settings.json`，并优先于 `.env`，容器重启后仍然生效。若登录页无法读取注册状态，会自动重试并显示明确的重试入口，不再静默隐藏。

### 5. 忘记默认账号密码怎么办？

个人桌面版生成本机随机凭据并自动登录，不使用固定默认密码。Web 版使用部署者配置的 `DEFAULT_EMAIL` 和初次建号时的密码。修改环境变量不会重置已有账号密码；先保留数据备份，不要删除数据库来尝试恢复。
