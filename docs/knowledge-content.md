# 内置学习内容

每个领域的核心知识只留一份快速提纲，保持打开即读、方便复习：

- 常考内容：先看需要复习哪些概念。
- 追问方向：了解面试可能怎样沿原理和场景深入。
- 知识提纲：按语言基础、机制与工程使用分组，每项只保留速查要点。

内置 12 个领域、12 份快速提纲；48 道含参考要点与追问的题目放在高频题库。沿用早期版本的短提纲阅读方式，保留基础覆盖，不拆成长文。Python 包括对象与容器、函数与资源、迭代与异步、并发取舍和工程习惯。

内容由 `src/study-content.ts` 与 `src/knowledge.ts` 独立组织。技术领域沿用通用名称，正文不复制旧版提纲。个人项目、简历和 JD 自行导入；学习内容不当作本人经历。

旧工作区只有正文哈希、标题和分类均匹配上次内置版本时才更新提纲。用户编辑、导入和 AI 补充的笔记保留。更新不回写旧面试快照；重启不复活已删除内容。
