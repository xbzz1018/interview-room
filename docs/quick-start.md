# 快速开始

先按 [部署说明](deployment.md) 启动；以下用于验证一轮个人练习。

## 登录与模型

- 个人桌面入口是项目根目录的 `启动面试练习室.cmd`。首次启动生成本机随机凭据并自动进入，不使用固定默认密码。
- Web 开发访问 `http://localhost:5173`；账号与密码使用部署者在 `.env` 中配置的值。
- 在设置中填写自己的模型 API 地址、模型 ID、Key 和协议。Embedding 用于检索，可选择本地 ONNX 或外部服务；本地模型首次下载需联网。

## 完成一轮

1. 在资料库上传或编辑项目说明、简历和 JD，也可在“我的简历”上传 PDF。
2. 从面试准备页选择这一轮的材料、目标岗位和模式。严格模拟先独立作答；教练练习允许请求提示。
3. 开始后材料快照固定。键盘可完成全流程，语音是可选项；离页后可从复盘与重练继续原会话。
4. 结束后阅读分阶段保存的报告，逐题生成参考答法，再用自己的话再次作答。
5. 查看引用原话的技术/表达缺口，选一个问题继续练；成功保存的练习刷新后仍可查看。

没有个人材料时，可用仓库的 [合成项目](../examples/project-brief.md) 与 [合成 JD](../examples/job-description.md) 验证流程。示例不代表真实经历。

详细的限额、草稿与恢复边界见 [模拟面试](resume-mock.md) 和 [项目案例](project-case.md)。
