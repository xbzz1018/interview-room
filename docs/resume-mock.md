# 个人材料与模拟面试

更新日期：2026-11-09，适用于“面试练习室”个人版。

## 准备一轮面试

1. 在“资料与学习 → 我的资料库”更新简历、项目说明、验证证据和目标岗位 JD。文本可以直接编辑；PDF/Office 等格式可以预览提取文本或替换文件。也可以在“我的简历”上传 PDF 供本轮使用。
2. 打开“开始面试 → 实时模拟”，选择本轮简历或项目资料，填写目标岗位，按需选择或粘贴 JD。不要求必须上传 PDF；只有 JD 不能作为候选人经历。
3. 确认模式：严格模拟先独立作答；教练练习可明确说“给我一个提示”或“讲解后让我重答”。教练练习保留观察，不进入独立作答分数趋势。
4. 开始后材料内容与版本冻结。此后编辑资料不会改变正在进行的面试。每轮最多选择 8 份资料库文档、48000 字，连同默认简历的完整快照最多 60000 字。
5. 回答时说明真实背景、本人职责、决策、取舍和验证。没有做过的部分明确说是设想或待验证，AI 协作也如实说明。

资料并不等于本人贡献：项目总体功能、个人实现与实习团队经历应分别讲清。未知经历与数字不应让模型代为编造。

## 继续已有面试

切页或重新打开时，从“复盘与重练”进入原会话。问答从服务端恢复，正在等待的回复会继续拉取；生成中断时可使用“重试上一条回答”。不要用新建一轮代替继续原会话。

未发送草稿按账户、会话保存在当前浏览器会话中，不保证关闭整个客户端后仍可恢复。已经提交的问答与成功保存的练习记录持久保留。

## 从复盘进入重练

结束后直接进入报告页。首段生成前展示等待状态，正文逐段保存；完整正文保存后即可阅读，画像在后台继续。画像失败可单独重试，不需要重新生成报告。

在“逐题参考答法”中选一道已经回答的问题，生成考察意图、回答框架、60–90 秒口述示例与后续追问。已生成内容会缓存，旧简历面试记录也支持。随后用自己的话“再次作答”，保存后查看原答与重答的比较。

重答不会覆盖原问答或原成绩。技术和表达缺口分别列出，并引用原答或重答中的原话，配一个下一步练法。完整结果保存后，刷新或从历史重开可恢复；每场最多保存 50 次重答。

模型等待与恢复边界见 [项目案例](project-case.md)，下一步验收标准见 [改进计划](project-roadmap.md)。
