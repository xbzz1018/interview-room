# 模型与资料检索配置

面试练习室围绕文字模拟面试、资料准备和复盘重练。无需配置麦克风、摄像头、语音转写、对象存储或联网公司搜索。

## 文字模型

在“模型与设置 → LLM 服务”填写 API Base、API Key、模型名和兼容模式。支持 Chat Completions 与 Responses，推理强度和自定义请求头按自己的网关填写。先测试连接，再保存；面试、报告与参考答法使用保存的模型，不会因功能精简更换模型。

凭据保存在本机用户目录，不应写入仓库、截图或普通日志。

## 资料检索

Embedding 用于知识库、个人材料与记忆检索，与生成回答的文字模型分别配置。

- 本地模式：可使用已验证的中文模型 `Xenova/bge-small-zh-v1.5`，缓存完成后无需额外的向量 API Key。
- API 模式：填写支持 Embedding 的 Base URL、Key、模型名及批大小；文字模型网关不一定提供向量接口。
- 更换 Embedding 后保存并重建索引，等待进度完成再使用检索。

PDF 应包含可复制文本，扫描件先做 OCR。桌面端需要保留整个程序目录以及后端资源。

## 历史数据

已移除录音复盘、实时语音辅助、声纹注册和音视频采集入口。已有相关记录仍可在历史页查看；不自动删除数据库、录音文件或旧凭据。保存模型设置也不会清空旧服务配置。旧任务在启动恢复时明确结束，不再调用语音供应商。

少量旧服务与契约代码继续用于历史数据兼容测试，生产入口不组装这些服务，公开 API 不包含相关路由。

启动与备份见 [部署说明](deployment.md)，模型字段见 [设置说明](settings.md)。
