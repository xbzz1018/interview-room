# 本机数据迁移

先保留并正常关闭 v1。新旧数据库结构不同，**不要直接替换数据库文件**。迁移工具只读旧版、写出新文件，新版预览后追加。

## 文字会话和资料

```powershell
npm run export:legacy -- --db "旧版数据目录/data.db" --user "自己的账号ID" --out "data/旧版文字备份.json" --with-knowledge
```

数据库位置和账号 ID 以你自己的本机目录为准。工具不枚举账号或读取凭据表，不把 API Key、登录信息、音视频或向量缓存带入。输出使用新建模式，不覆盖已有备份。

导出包括该账号 resume、topic_drill、jd_prep 等文字会话；简历面试按相邻的面试官/候选人消息配对，参考答法和重答按题目 ID 关联。无法可靠配对的记录会提示，不能根据序号猜测。找到历史冻结材料时保留；没有快照就提示，不拿现有简历替换当时依据。

资料库仅直接读取 MD/TXT，PDF 或其他文件会提示重新上传。加 `--with-knowledge` 才读取该账号 knowledge 与 high_freq 下的 Markdown，以及该账号 topics.json 的领域名称与目录映射。核心知识与高频题分别标记，导入后保持领域分类；没有映射时按安全目录名保留领域。符号链接跳过。旧复杂简历排版、自动画像和来源检索索引不包含在这个导出中。

新版打开“模型与设置 → 选择备份并预览”，核对数量与警告，再确认追加。历史面试按已结束归档导入，不恢复旧版进行中的状态。重复记录跳过，不覆盖个人改动。请保留原始数据目录。

## 已整理的题卡与源码来源包

已有明确 `projects` / `topics` 的准备包可转换：

```powershell
npm run convert:prep -- --input "本机准备包.json" --out "data/准备包待导入.json"
```

准备包格式：

```json
{
  "projects": [{
    "name": "合成项目",
    "sources": [{
      "path": "src/example.ts",
      "kind": "current_source",
      "start_line": 12,
      "content": "明确提供的源码片段",
      "sha256": "原始来源元数据"
    }]
  }],
  "topics": [{
    "name": "数据库",
    "cards": [{"filename": "A01.md", "content": "学习题卡内容"}]
  }]
}
```

转换器不跟随 path 读取电脑文件，不扫描代码库。路径、行号和声明的哈希只用于追溯，不等于实测证明。知识按领域合并，较长内容拆成多份；在新版预览后选所需资料开始练习。导入后要核对性质与内容，题卡不能当作本人实习成果。

## 新版自身备份

导出文字备份包含领域、知识分类与专项历史快照，不包含 Key、任何模型配置、运行中的任务和未保存浏览器草稿。导入先预览，同 ID 或同名领域复用，资料与会话按 ID 去重并追加；领域缺失的知识正文放到未分类并提示，所有导入会话都作为已结束档案。保留正在练习的状态需要正常保存当前应用数据；复制整库前先退出服务，整库含凭据，不要上传 GitHub。
