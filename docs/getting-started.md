# 第一次练习怎么安排

先完成 [快速开始](quick-start.md)。目标是把真实经历讲清楚，再通过证据改进下一次回答。

## 先准备材料

把简历、项目说明和 JD 放进资料库。项目说明区分业务背景、本人职责、团队实现与个人复现，记录可核对的代码位置、参数和验证结论。缺失数字与未做过的部分标为待补充，不让模型替你编造。

每轮选择少量相关材料。开始时保存快照，后续修改原资料不会改变旧面试依据。

## 先独立答，再参考，再重答

用严格模拟检查独立表达；需要学习原理时选择教练练习。结束后先读报告的一项具体缺口，再打开对应问题的参考答法，用自己的话重新回答并保存比较。参考答法需要人工核实，不能直接当作标准答案或本人经历。

从“复盘与重练”回到原会话，可查看问答、成功生成的答法和重答记录。未提交草稿只在当前浏览器会话中保存，未完成报告与重答的恢复边界见 [案例](project-case.md)。

## 再选择专项与工具

- 知道薄弱主题后，用专项训练集中练一个点，并维护对应知识材料。
- 有明确岗位时，用 JD 备面补充准备，再带入模拟。
- 能力记录与画像用于观察多轮信号，单次模型评分不应成为永久结论。
- 录音复盘、知识库、图谱和 Copilot 在更多工具中；可选语音服务的配置见 [外部服务](external-services.md)。

顶部、侧栏和设置都可以切换三套配色。没有语音配置也可以先用键盘完成核心练习。
