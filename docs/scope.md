# 功能范围

更新：2026-11-16。保留熟悉的文字训练方式，简历、目标岗位和 JD 由使用者选择；界面与页面组织独立实现。

| v1 能力 | v2 当前处理 |
| --- | --- |
| 简历、岗位、JD 定向模拟 | 保留。简历/JD 分开选择，岗位必填，项目和笔记补充证据 |
| JD 备面预览 | 提供按需备面分析，说明岗位重点、已有经历与缺少证据，不生成匹配分数 |
| 专项练习 | 独立导航和准备草稿；选择领域及其核心知识/高频题，专项重点可选，支持通用技术和个人材料定向练习；共用问答、复盘和重答流程 |
| 资料预览、文本编辑、版本冲突 | 保留。文本/PDF/DOCX/图片提取后核对保存；旧会话保留旧内容 |
| 我的简历 | 独立入口，只显示简历，新增时预选简历类型。支持导入与文本编辑；复杂模板排版编辑器不保留 |
| 知识库和题卡 | 按领域分核心知识/高频题，内置 12 个通用领域、24 份文件及 48 道带参考要点的题目；每领域核心知识一份快速提纲，高频题另放；个人新增多份时才显示选择器。支持领域 CRUD、文件编辑搜索、批量文档导入、主动 AI 补充与专项选材；只保存后生效 |
| 多模型设置 | 独立保存多份国内外模型连接，提供八种服务商/网关模板，支持 Responses、Chat 与 Anthropic Messages；分别测试与启用，Key 不互相继承，在跑任务不受切换影响 |
| 源码与题卡引用 | 可从明确的准备包转换资料，保留来源路径、行号和性质。v2 暂用所选全文，无 v1 按问题检索四个源码片段的独立服务 |
| 问答历史与切页恢复 | 正式记录保存在 SQLite；浏览器草稿按会话和问题保存 |
| 严格模拟与教练练习 | 保留。严格模拟进行中不提供参考和重答；重答不能覆盖原回答 |
| 报告、参考答法、重答 | 分别按需生成并缓存；草稿片段可看，任务取消/中断可手动重试 |
| 能力记录 | 独立入口汇总轮次、原答、参考、重答与复盘，展示最近十条改进记录并回到原轮次；当前没有自动画像、分数趋势和跨轮推荐 |
| 本机草稿 | 当前浏览器固定来源恢复，未实现 v1 Electron userData 的跨端口桌面草稿 |
| 数据迁移 | 新备份预览/追加/去重；旧文字会话、知识文件和参考答法可只读导出，历史会话按归档导入 |
| 桌面包 | Electron 独立窗口与 Windows x64 文件夹版；保留网页版。桌面与网页可指定相同数据目录；未提供安装器、签名和自动更新 |

移除音频、录音、实时 Copilot、图谱、套餐、支付、赞助及云平台账户。图片仅用于经确认后的材料识别，不启用摄像头或录屏。

旧版本在归档分支保留。新旧数据库独立，不自动迁移个人资料；需要时先只读导出，再预览追加。

默认只提供通用学习内容，不包含维护者或用户的个人项目。简历、JD、项目和后续笔记由使用者自行导入。知识提纲与参考答法用于练习，需要核对版本与事实；不提供“唯一标准答案”或预置的个人实习成绩。

左栏保留开始面试、复盘与重练、资料与学习、我的简历、专项练习、能力记录和备面知识库；底部是模型与设置。页面视觉独立实现，雾白墨蓝、深灰青绿两套主题共享相同功能。旧酒红配置读取为浅色，不改模型参数。桌面固定窗口、分区滚动；知识正文与领域列表分别滚动，准备页和模型表单的操作区固定。小屏改为两行训练导航。
